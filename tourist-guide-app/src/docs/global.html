(async) getDirections() → {void}

Fetches directions from the Google Directions API and processes the route data. This function sends a request to the Google Directions API to get driving directions from the current location to the specified destination. It processes the response to extract the coordinates of the route steps and updates the state with the first route's steps. If either the location or destination is missing, an alert is shown to the user.

(async) getLocation() → {Promise.<(Object|null)>}

Requests location permissions and retrieves the current position of the user. This function requests permission to access the device's location and, if granted, fetches the current location of the user. If permission is denied, an alert is shown.
